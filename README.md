## 📝 Descripción

PetCare es una aplicación desarrollada en equipo como proyecto integrador de Frontend II.

El sistema permite trabajar con solicitudes de adopción de mascotas mediante formularios, tablas y lógica de procesamiento implementada en JavaScript y React.

## ✨ Funcionalidades

- Formulario para solicitudes de adopción
- Visualización de animales en tablas
- Procesamiento de datos mediante lógica en JavaScript
- Uso de componentes reutilizables en React
- Manejo del estado de la aplicación

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- Vite
- CSS

## 👥 Modalidad del proyecto

Proyecto académico colaborativo desarrollado en equipo para la asignatura Frontend II.

Este repositorio corresponde a una bifurcación del repositorio original del grupo.

## 🎯 Objetivo

Aplicar los conocimientos adquiridos en React, componentes, manejo de estado y lógica de programación dentro de una aplicación web funcional.

Proyecto académico finalizado.
